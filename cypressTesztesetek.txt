/*
📝 HIÁNYZÓ TESZTEK (AMIKET ÉRDEMES MEGÍRNI):

1. localStorage tesztek:
   - PHP kiválasztás → localStorage 'tema' = 'PHP'
   - JavaScript kiválasztás → localStorage 'tema' = 'JavaScript'  
   - Java kiválasztás → localStorage 'tema' = 'Java'
   - Nincs téma esetén hibaüzenet

2. Helyes/rossz válasz színezés:
   - Helyes válasz → 'helyes' CSS osztály
   - Rossz válasz → 'rossz' CSS osztály

3. Válasz után letiltás:
   - pointer-events: none a válaszokon
   - reset gomb letiltása (opacity + pointer-events)

4. Modal működés:
   - Reset gomb megnyitja a modalt
   - 'Igen' gomb újraindít
   - 'Mégse' gomb bezár

5. Kvíz vége:
   - Eredmény kiírása (pl. "Eredmény: 15 / 20")
   - Újraindítás gomb

6. Reszponzivitás:
   - 375px: válaszok egymás alatt
   - 768px: kártyák egymás alatt
   - 1200px: minden normál nézetben

7. Hibakezelés:
   - Üres localStorage 'tema' esetén hibaüzenet
   - Nem létező téma esetén 'Nincs ilyen téma!' üzenet
*/
